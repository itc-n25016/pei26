1.算術演算子（計算を行う）
数値の足し算や掛け算などに使います。
・+ :加算（足し算）
・- :減算（引き算）
・* :乗算（掛け算）
・/ :除算（割り算）
・% または Mod :剰余（割り算の余り）
・** または ^ :べき乗（◯乗）


2. 比較演算子（大小や等しさを比べる）
2つの値を比較し、条件に当てはまるか（真・偽）を返します。
• == または = ：等しい（左辺と右辺が同じ）
• != または <> ：等しくない（異なる）
• < ：より小さい（未満）
• <= ：以下（小さい、または等しい）
• > ：より大きい（超える）
• >= ：以上（大きい、または等しい）


3. 論理演算子（複数の条件を組み合わせる）
「かつ」「または」「否定」など、条件を複雑に組み立てるときに使います。
• && または and （言語により And）：論理積（かつ・両方が成り立つ場合に真）
• || または or （言語により Or）：論理和（または・どちらか一方が成り立つ場合に真）
• ! または not （言語により Not）：否定（でない・結果を反転させる）


4. 代入演算子（変数に値を入れる・更新する）
基本の = に加え、計算と代入を同時に行う「累算代入演算子」や、Python 3.8以降で導入された「セイウチ演算子」があります。
• =：基本的な代入。右辺の値を左辺の変数に入れます（例：x = 10）。
• +=：加算して代入。x += 3 は x = x + 3 と同じ意味です。
• -=：減算して代入。x -= 3 は x = x - 3 と同じ意味です。
• *=：乗算して代入。x *= 3 は x = x * 3 と同じ意味です。
• /=：除算して代入。x /= 3 は x = x / 3 と同じ意味です。
• //=：切り捨て除算して代入。x //= 3 は x = x // 3 と同じ意味です。
• %=：余りを計算して代入。x %= 3 は x = x % 3 と同じ意味です。
• **=：べき乗を計算して代入。x **= 3 は x = x ** 3 と同じ意味です。
• :=（セイウチ演算子）：式の中で変数に値を代入しつつ、その値自体を返します。if 文や while 文の条件式を短く書くときに便利です。


5. ビット演算子（2進数レベルでの操作）
数値を内部的な2進数（例：5 は 0101、3 は 0011）として扱い、各桁（ビット）ごとに論理演算やシフト（ずらし）を行います。データ圧縮やフラグ管理、高速な計算などで使われます。
• &（ビット論理積 / AND）：両方のビットが 1 のときだけ 1 にします。（例：5 & 3 → 0101 & 0011 = 0001 → 1）
• |（ビット論理和 / OR）：どちらかのビットが 1 なら 1 にします。（例：5 | 3 → 0101 | 0011 = 0111 → 7）
• ^（ビット排他的論理和 / XOR）：2つのビットが異なるときだけ 1 にします。（例：5 ^ 3 → 0101 ^ 0011 = 0110 → 6）
• ~（ビット反転 / NOT）：すべてのビットの 0 と 1 を反転させます。Pythonでは ~x は -(x + 1) になります。（例：~5 → -6）
• <<（左シフト）：ビットを指定した数だけ左にずらし、空いた右端に 0 を埋めます。1つずらすごとに値が2倍になります。（例：5 << 1 → 0101 が 1010 になり 10）
• >>（右シフト）：ビットを指定した数だけ右にずらし、はみ出た分を切り捨てます。1つずらすごとに値が半分（切り捨て）になります。（例：5 >> 1 → 0101 が 0010 になり 2）
